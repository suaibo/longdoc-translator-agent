# LongDoc Translator Agent 接口说明

版本：v0.2
接口前缀：`/api`  
适用范围：MVP 论文翻译模式

---

## 1. 通用规范

### 1.1 Base URL

本地开发：

```text
http://localhost:8000/api
```

同一 FastAPI 进程挂载 Gradio 工作台：

```text
http://localhost:8000/ui
```

Gradio handler 直接调用应用 Service；REST API 仍是外部客户端、自动化测试和后续独立前端的公共接口。

### 1.2 响应格式

除文件下载接口外，所有接口统一返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

失败响应：

```json
{
  "code": 40001,
  "message": "参数校验失败",
  "data": null
}
```

### 1.3 错误码

| 错误码 | 说明 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40002 | 文件类型不支持 |
| 40003 | 文件过大 |
| 40401 | 任务不存在 |
| 40402 | 输出文件不存在 |
| 40901 | 当前状态不允许操作 |
| 40902 | 单任务队列忙 |
| 50001 | 系统内部错误 |
| 50002 | Docling 解析失败 |
| 50003 | LLM 调用失败 |

### 1.4 文件限制

MVP 文件限制：

- 支持扩展名：`.pdf`、`.md`、`.txt`
- 最大文件大小：50MB
- MVP 不支持压缩包上传

## 3.2 创建翻译任务

```http
POST /api/jobs
```

Content-Type：

```http
multipart/form-data
```

表单参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| file | file | 是 | PDF / Markdown / TXT 文件 |
| mode | string | 否 | MVP 默认 `paper` |
| ocrMode | string | 否 | `auto / off / force`，默认 `auto`；仅 PDF 生效 |
| requireHighRiskReview | boolean | 否 | 高风险 chunk 翻译后是否中断审核 |
| requireChapterReview | boolean | 否 | 每个章节翻译结束后是否中断审核 |

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001"
  }
}
```

业务规则：

- 只允许 `.pdf`、`.md`、`.txt`。
- 文件最大 50MB。
- `ocrMode` 只允许 `auto / off / force`；Markdown 和 TXT 可省略该字段。
- 当存在运行中任务时返回 `40902`。
- 创建成功后，后台 worker 自动执行解析、切分和术语抽取。

可能错误：

- `40002` 文件类型不支持
- `40003` 文件过大
- `40902` 单任务队列忙

## 3.5 查询术语表

```http
GET /api/jobs/{jobId}/terms
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "termId": "term_001",
      "sourceTerm": "checkpoint",
      "suggestedTranslation": "检查点",
      "confirmedTranslation": null,
      "note": "用于长任务恢复",
      "confirmed": false
    }
  ]
}
```

业务规则：

- 任务必须至少进入 `WAITING_TERM_REVIEW`。
- 未抽取完成时返回空数组或当前已有术语。

---

## 3.6 确认术语表

```http
PUT /api/jobs/{jobId}/terms
```

请求体：

```json
{
  "terms": [
    {
      "termId": "term_001",
      "confirmedTranslation": "检查点",
      "note": "保留技术术语译法"
    }
  ]
}
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "TRANSLATING"
  }
}
```

业务规则：

- 任务状态必须是 `WAITING_TERM_REVIEW`。
- 所有术语必须有 `confirmedTranslation`。
- Agent 未抽取到术语时允许提交空 `terms` 数组，用于解除人工确认中断并继续流程。
- 确认后任务进入 `TRANSLATING`，后台 worker 继续翻译。

可能错误：

- `40401` 任务不存在
- `40901` 当前状态不允许操作
- `40001` 参数校验失败

---

## 3.7 查询分块列表

```http
GET /api/jobs/{jobId}/chunks
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "chunkId": "chunk_001",
      "chunkIndex": 0,
      "sectionTitle": "Abstract",
      "chunkType": "TEXT",
      "status": "COMPLETED",
      "hasRisk": false,
      "riskTypes": [],
      "riskSummary": null,
      "sourcePreview": "This paper proposes...",
      "translatedPreview": "本文提出...",
      "translatedAt": "2026-06-23T14:10:00+08:00"
    }
  ]
}
```

说明：

- `chunkType` 可选值：`TEXT / TABLE / FORMULA / PICTURE / CODE`。
- `riskTypes` 是去重后的风险类型数组，可选值：`TABLE / FORMULA / REFERENCE / STRUCTURE / LONG_PARAGRAPH / PARSER_WARNING`。
- `sourcePreview` 和 `translatedPreview` MVP 只返回前 120 字符，用于控制台展示。
- 完整原文和译文在导出文件中查看。
- 当前接口返回 `sectionPath / boundaryReason / boundaryScore / semanticTopic`。

## 3.8 下载输出文件

```http
GET /api/jobs/{jobId}/outputs/{type}
```

路径参数：

| 参数 | 说明 |
| --- | --- |
| type | `bilingual` / `translated` / `report` / `bilingual_html` / `translated_html` / `package` |

响应：

- 成功时返回文件流。
- 文件名分别为：`bilingual.md`、`translated.md`、`report.md`。

业务规则：

- 任务必须是 `COMPLETED`。
- 输出文件不存在时返回 `40402`。

可能错误：

- `40401` 任务不存在
- `40402` 输出文件不存在
- `40901` 当前状态不允许操作

---

## 3.9 继续任务

```http
POST /api/jobs/{jobId}/resume
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "TRANSLATING"
  }
}
```

业务规则：

- 任务状态必须是 `FAILED`。
- 后端从最近一个 checkpoint 或已完成 chunk 继续。
- 如果存在其他运行中任务，返回 `40902`。

---

## 3.10 取消任务

```http
POST /api/jobs/{jobId}/cancel
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "CANCELLED"
  }
}
```

业务规则：

- `COMPLETED` 状态不允许取消。
- `CANCELLED` 状态不允许恢复。
- 后台 worker 应在 chunk 边界检查取消状态。

---

## 3.11 查询工作流事件

```http
GET /api/jobs/{jobId}/events
```

响应按创建时间升序返回节点生命周期事件：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "eventId": "event_xxx",
      "node": "translate_chunk",
      "eventType": "NODE",
      "status": "FAILED",
      "message": "provider timeout",
      "elapsedMs": 1200,
      "metadata": {"chunkIndex": 2},
      "createdAt": "2026-06-24T10:00:00+08:00"
    }
  ]
}
```

事件状态包括 `STARTED / COMPLETED / INTERRUPTED / FAILED`。事件写入失败只记录
服务日志，不覆盖原工作流异常。

---

## 3.12 查询与批准人工审核

```http
GET /api/jobs/{jobId}/reviews
POST /api/jobs/{jobId}/reviews/{reviewId}/approve
```

审核类型为 `HIGH_RISK_CHUNK` 或 `CHAPTER`。批准请求可携带可选 `note`；
后端先持久化审核结果并将任务恢复为 `TRANSLATING`，再使用
`Command(resume)` 继续原 LangGraph 线程。重复批准返回 `40901`。

## 4. 前端轮询建议

- 创建任务后每 2 秒轮询 `GET /api/jobs/{jobId}`。
- 当状态是 `WAITING_TERM_REVIEW` 时停止自动推进，展示术语确认页。
- 当状态是 `TRANSLATING` 时继续轮询任务详情和 chunk 列表。
- 当状态是 `COMPLETED` 时展示下载入口。
- 当状态是 `FAILED` 时展示错误和恢复按钮。
- 同时轮询事件接口，用时间线展示节点耗时、中断和最近失败节点。

---

## 5. 接口验收标准

- 所有 JSON 接口都使用统一响应体。
- 基础文件下载接口能返回真实 Markdown 文件；输出增强接口实现后还需返回 HTML、原始文件和结果包。
- 错误码与错误场景一致。
- 状态不允许操作时返回 `40901`。
- 单任务队列忙时返回 `40902`。
- 前端可以只依赖这些接口完成 MVP 演示流程。

---

## 6. 文档结构与输出增强接口

本节接口已经实现，并保持三个 Markdown 下载类型向后兼容。

### 6.1 ChunkVO 可选增强字段

```json
{
  "chunkId": "chunk_001",
  "sectionTitle": "Training",
  "sectionPath": ["Method", "Model", "Training"],
  "boundaryReason": "SEMANTIC_SHIFT",
  "boundaryScore": 0.82,
  "semanticTopic": "training objective"
}
```

约束：

- 硬结构边界的 `boundaryScore` 可以为 `null`。
- `semanticTopic` 仅用于解释和调试，不作为翻译正确性依据。
- 当前规则基线生成的历史 chunk 可以不包含这些字段。

### 6.2 输出类型扩展

现有：

```text
bilingual
translated
report
```

目标增加：

```text
bilingual_html
translated_html
package
```

调用方式保持：

```http
GET /api/jobs/{jobId}/outputs/{type}
```

建议文件名：

| type | 文件名 | 定位 |
| --- | --- | --- |
| `bilingual_html` | `bilingual.html` | 双语直接阅读 |
| `translated_html` | `translated.html` | 中文直接阅读 |
| `package` | `result.zip` | 携带所有文档和相对资产 |

### 6.3 下载原始文件

```http
GET /api/jobs/{jobId}/source
```

规则：

- 返回用户上传的原始文件流和安全文件名。
- PDF 必须完整返回，不重新编码或覆盖。
- 该文件是原始资料，不得标记为翻译 PDF。
- 任务存在即可下载，不要求 `COMPLETED`。

可能错误：

- `40401` 任务不存在
- `40402` 原始文件不存在

### 6.4 查询输出清单

```http
GET /api/jobs/{jobId}/outputs
```

目标响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "type": "bilingual_html",
      "filename": "bilingual.html",
      "mediaType": "text/html",
      "available": true
    },
    {
      "type": "package",
      "filename": "result.zip",
      "mediaType": "application/zip",
      "available": true
    }
  ]
}
```

前端应根据服务端清单展示按钮，不在本地硬编码尚未生成的输出。

### 6.5 兼容性

- 三个 Markdown 类型继续保留。
- HTML 内的表格、公式和图片通过相对资源或内嵌样式完整渲染。
- `result.zip` 包含原始文件、Markdown、HTML、report、manifest 和 assets。
- 单独下载 Markdown 时，接口应提示它可能依赖结果包中的相对资产；最终阅读优先推荐 HTML 或 package。
### 6.6 下载与内容安全

- 所有下载响应使用安全的 `Content-Disposition` 文件名，不把用户文件名解释为服务器路径。
- HTML 输出不包含源文档脚本、事件属性或未允许的 iframe。
- `result.zip` 内不得包含绝对路径、盘符或 `../` 路径。
- manifest 仅返回输出根目录内的相对路径。
- HTML/ZIP 尚未生成时返回 `40402`，不能返回半成品文件。
