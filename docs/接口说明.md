# LongDoc Translator Agent 接口说明

版本：v0.1  
接口前缀：`/api`  
适用范围：MVP 论文翻译模式

---

## 1. 通用规范

### 1.1 Base URL

本地开发：

```text
http://localhost:8000/api
```

### 1.2 响应格式

除文件下载接口外，所有接口统一返回：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

失败响应：

```json
{
  "code": 40001,
  "message": "参数校验失败",
  "data": null
}
```

### 1.3 错误码

| 错误码 | 说明 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数校验失败 |
| 40002 | 文件类型不支持 |
| 40003 | 文件过大 |
| 40401 | 任务不存在 |
| 40402 | 输出文件不存在 |
| 40901 | 当前状态不允许操作 |
| 40902 | 单任务队列忙 |
| 50001 | 系统内部错误 |
| 50002 | Docling 解析失败 |
| 50003 | LLM 调用失败 |

### 1.4 文件限制

MVP 文件限制：

- 支持扩展名：`.pdf`、`.md`、`.txt`
- 最大文件大小：50MB
- MVP 不支持压缩包上传

## 3. 接口列表

## 3.1 健康检查

```http
GET /api/health
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "UP",
    "service": "longdoc-translator-agent"
  }
}
```

---

## 3.2 创建翻译任务

```http
POST /api/jobs
```

Content-Type：

```http
multipart/form-data
```

表单参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| file | file | 是 | PDF / Markdown / TXT 文件 |
| mode | string | 否 | MVP 默认 `paper` |
| ocrMode | string | 否 | `auto / off / force`，默认 `auto`；仅 PDF 生效 |

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001"
  }
}
```

业务规则：

- 只允许 `.pdf`、`.md`、`.txt`。
- 文件最大 50MB。
- `ocrMode` 只允许 `auto / off / force`；Markdown 和 TXT 可省略该字段。
- 当存在运行中任务时返回 `40902`。
- 创建成功后，后台 worker 自动执行解析、切分和术语抽取。

可能错误：

- `40002` 文件类型不支持
- `40003` 文件过大
- `40902` 单任务队列忙

## 3.5 查询术语表

```http
GET /api/jobs/{jobId}/terms
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "termId": "term_001",
      "sourceTerm": "checkpoint",
      "suggestedTranslation": "检查点",
      "confirmedTranslation": null,
      "note": "用于长任务恢复",
      "confirmed": false
    }
  ]
}
```

业务规则：

- 任务必须至少进入 `WAITING_TERM_REVIEW`。
- 未抽取完成时返回空数组或当前已有术语。

---

## 3.6 确认术语表

```http
PUT /api/jobs/{jobId}/terms
```

请求体：

```json
{
  "terms": [
    {
      "termId": "term_001",
      "confirmedTranslation": "检查点",
      "note": "保留技术术语译法"
    }
  ]
}
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "TRANSLATING"
  }
}
```

业务规则：

- 任务状态必须是 `WAITING_TERM_REVIEW`。
- 所有术语必须有 `confirmedTranslation`。
- Agent 未抽取到术语时允许提交空 `terms` 数组，用于解除人工确认中断并继续流程。
- 确认后任务进入 `TRANSLATING`，后台 worker 继续翻译。

可能错误：

- `40401` 任务不存在
- `40901` 当前状态不允许操作
- `40001` 参数校验失败

---

## 3.7 查询分块列表

```http
GET /api/jobs/{jobId}/chunks
```

响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "chunkId": "chunk_001",
      "chunkIndex": 0,
      "sectionTitle": "Abstract",
      "chunkType": "TEXT",
      "status": "COMPLETED",
      "hasRisk": false,
      "riskTypes": [],
      "riskSummary": null,
      "sourcePreview": "This paper proposes...",
      "translatedPreview": "本文提出...",
      "translatedAt": "2026-06-23T14:10:00+08:00"
    }
  ]
}
```

说明：

- `chunkType` 可选值：`TEXT / TABLE / FORMULA / PICTURE / CODE`。
- `riskTypes` 是去重后的风险类型数组，可选值：`TABLE / FORMULA / REFERENCE / STRUCTURE / LONG_PARAGRAPH / PARSER_WARNING`。
- `sourcePreview` 和 `translatedPreview` MVP 只返回前 120 字符，用于控制台展示。
- 完整原文和译文在导出文件中查看。

---

## 3.8 下载输出文件

```http
GET /api/jobs/{jobId}/outputs/{type}
```

路径参数：

| 参数 | 说明 |
| --- | --- |
| type | `bilingual` / `translated` / `report` |

响应：

- 成功时返回文件流。
- 文件名分别为：`bilingual.md`、`translated.md`、`report.md`。

业务规则：

- 任务必须是 `COMPLETED`。
- 输出文件不存在时返回 `40402`。

可能错误：

- `40401` 任务不存在
- `40402` 输出文件不存在
- `40901` 当前状态不允许操作

---

## 3.9 继续任务

```http
POST /api/jobs/{jobId}/resume
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "TRANSLATING"
  }
}
```

业务规则：

- 任务状态必须是 `FAILED`。
- 后端从最近一个 checkpoint 或已完成 chunk 继续。
- 如果存在其他运行中任务，返回 `40902`。

---

## 3.10 取消任务

```http
POST /api/jobs/{jobId}/cancel
```

成功响应：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "jobId": "job_20260623_001",
    "status": "CANCELLED"
  }
}
```

业务规则：

- `COMPLETED` 状态不允许取消。
- `CANCELLED` 状态不允许恢复。
- 后台 worker 应在 chunk 边界检查取消状态。

---

## 4. 前端轮询建议

- 创建任务后每 2 秒轮询 `GET /api/jobs/{jobId}`。
- 当状态是 `WAITING_TERM_REVIEW` 时停止自动推进，展示术语确认页。
- 当状态是 `TRANSLATING` 时继续轮询任务详情和 chunk 列表。
- 当状态是 `COMPLETED` 时展示下载入口。
- 当状态是 `FAILED` 时展示错误和恢复按钮。

---

## 5. 接口验收标准

- 所有 JSON 接口都使用统一响应体。
- 文件下载接口能返回真实 Markdown 文件。
- 错误码与错误场景一致。
- 状态不允许操作时返回 `40901`。
- 单任务队列忙时返回 `40902`。
- 前端可以只依赖这些接口完成 MVP 演示流程。
